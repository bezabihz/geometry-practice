Chapter 2 — The Logic of Geometry

This chapter teaches you to argue rigorously. You will learn how to spot a pattern, write a precise conditional, recognize its converse and contrapositive, chain statements together using the laws of logic, and produce formal two-column proofs.

1 Vocabulary

Conjecture
An educated guess based on observation. May be true or false.
Counterexample
A single example that proves a conjecture false.
Conditional
An "if–then" statement: If p, then q. Notation: p → q.
Hypothesis
The "if" part of a conditional (p).
Conclusion
The "then" part of a conditional (q).
Truth value
Either true (T) or false (F).
Negation (~p)
The opposite truth value of p. If p is true, ~p is false.
Biconditional
"p if and only if q": p ↔ q. True only when p and q have the same truth value.
Theorem
A statement that has been proven.
Postulate / Axiom
A statement accepted without proof.
Proof
A logical argument that establishes a statement as true using definitions, postulates, theorems, and given information.

2 Inductive Reasoning

Inductive reasoning = drawing a general conclusion from specific examples (pattern → rule). It can suggest truth but never prove truth.

Pattern → conjecture → counterexample search. The strength of an inductive argument depends on how many varied cases support it, but one counterexample destroys it.
Example · Pattern
Find the next term: 2, 5, 10, 17, 26, __
  1. Differences: 3, 5, 7, 9 — arithmetic with difference 2.
  2. Next difference = 11; next term = 26 + 11 = 37.
  3. Closed form: aₙ = n² + 1.
Next term = 37

3 Conditional Statements & Related Forms

From any conditional p → q we can write three related statements:

FormNotationStatement
Conditionalp → qIf p, then q.
Converseq → pIf q, then p. (Swap)
Inverse~p → ~qIf not p, then not q. (Negate)
Contrapositive~q → ~pIf not q, then not p. (Swap & Negate)
Logical Equivalences
Key Pairs
A conditional is logically equivalent to its contrapositive. The converse is logically equivalent to the inverse. Equivalent statements share the same truth value in every case.
A true conditional does not guarantee its converse is true. Example: "If it's a square, then it's a rectangle" is true, but "If it's a rectangle, then it's a square" is false.

4 Biconditional Statements & Definitions

Definition
Biconditional
"p if and only if q" (written p ↔ q) means both p → q AND q → p are true.
A good definition can be written as a true biconditional. Every definition you've learned (midpoint, angle bisector, perpendicular, etc.) works both directions.

Example: "An angle is a right angle ↔ its measure is 90°." Both directions are true; this is a valid definition.

5 Deductive Reasoning & Laws of Logic

Deductive reasoning = using definitions, postulates, and previously-proven theorems to draw a guaranteed conclusion. Unlike inductive reasoning, deduction proves truth.

Law of Detachment
(Modus Ponens)
If p → q is true and p is true, then q is true.
Law of Syllogism
(Transitivity of Implication)
If p → q and q → r are both true, then p → r is true.
Law of Contrapositive
(Modus Tollens)
If p → q is true and q is false, then p is false.
Two classic invalid arguments to avoid:
  • Affirming the consequent: p → q is true and q is true, therefore p is true. (Invalid.)
  • Denying the antecedent: p → q is true and p is false, therefore q is false. (Invalid.)

6 Properties of Equality (Algebraic Reasoning)

These are justified steps you can cite in proofs. Let a, b, c be real numbers.

PropertyStatement

TransitiveIf a = b and b = c, then a = c.
AdditionIf a = b, then a + c = b + c.
SubtractionIf a = b, then a − c = b − c.

7 Properties of Congruence

Congruence of segments/angles follows the same three structural properties as equality:

Theorem 2-1
Reflexive Property of Congruence
AB ≅ AB; ∠A ≅ ∠A.
Theorem 2-2
Symmetric Property of Congruence
If AB ≅ CD, then CD ≅ AB.
Theorem 2-3
Transitive Property of Congruence
If AB ≅ CD and CD ≅ EF, then AB ≅ EF.
In a two-column proof, use the Reflexive property whenever a shared side or shared angle appears in two figures being compared — it's nearly always a step in CPCTC-style proofs.

8 Two-Column & Paragraph Proofs

A two-column proof has numbered Statements on the left and matching Reasons on the right. Every statement must be a given, definition, postulate, theorem, or property.

Anatomy of a proof

  1. Start with what is Given.
  2. End with what is to be Proven.
  3. Each step has a justification (definition, postulate, theorem, property).
  4. The diagram is a starting point — only state what's given or proven, never what merely "looks true."

Theorems proven in Chapter 2

Theorem 2-4
Congruent Supplements Theorem
If two angles are supplementary to the same angle (or to congruent angles), then the two angles are congruent.
Theorem 2-5
Congruent Complements Theorem
If two angles are complementary to the same angle (or to congruent angles), then the two angles are congruent.
Theorem 2-6
All Right Angles Congruent
All right angles are congruent.
Theorem 2-7
Perpendicular ⇒ Four Right Angles
If two lines are perpendicular, then they form four right angles.
Theorem 2-8
Vertical Angles Theorem
Vertical angles are congruent.

9 Worked Examples

Example 1 · Conditional Forms
Write the converse, inverse, and contrapositive of: "If two angles are vertical, then they are congruent."
  1. Converse: If two angles are congruent, then they are vertical. (False — counterexample: any congruent non-vertical pair.)
  2. Inverse: If two angles are not vertical, then they are not congruent. (False — same counterexample.)
  3. Contrapositive: If two angles are not congruent, then they are not vertical. (True — equivalent to original.)
Example 2 · Law of Syllogism
Given: "If it rains, then the field is wet." and "If the field is wet, then practice is cancelled." Conclude?
  1. p: rain · q: field wet · r: practice cancelled.
  2. p → q and q → r are given.
  3. By the Law of Syllogism: p → r: "If it rains, then practice is cancelled."
Example 3 · Two-column proof
Given m∠1 + m∠2 = 90° and m∠2 = 60°. Prove m∠1 = 30°.
StatementsReasons
1. m∠1 + m∠2 = 90°Given
2. m∠2 = 60°Given
3. m∠1 + 60° = 90°Substitution Property
4. m∠1 = 30°Subtraction Property of Equality

10 Common Pitfalls

  • "True" for the original conditional does not make the converse true. Test each one.
  • Don't confuse inductive (pattern → guess) with deductive (rules → guaranteed conclusion).
  • Every step in a proof needs a reason. "By the diagram" is never a reason.
  • "Given" only justifies the literal text of the hypothesis — anything else needs to be derived.
  • Substitution replaces one expression with an equal one. Transitive chains a=b=c ⇒ a=c. They're related but distinct reasons.
  • A biconditional is true only when both directions are true — if either direction fails, the biconditional is false.
