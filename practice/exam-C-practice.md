## Part 2 — Reasoning and Proof (Ch. 2)

---

**Question 9.**
Which statement is the **inverse** of "If a polygon is a triangle, then it has exactly three sides"?

- A) If a polygon has exactly three sides, then it is a triangle.
- B) If a polygon does not have exactly three sides, then it is not a triangle.
- C) If a polygon is not a triangle, then it does not have exactly three sides.
- D) A polygon is a triangle if and only if it has three sides.

---

**Question 10.**
Given: "All rectangles are parallelograms." and "ABCD is a rectangle." What can be concluded by the Law of Detachment?

- A) ABCD has four right angles.
- B) ABCD is a parallelogram.
- C) All parallelograms are rectangles.
- D) ABCD has congruent diagonals.

---

**Question 11.**
A student writes: "If I study, then I pass. If I pass, then I graduate." Using the Law of Syllogism, which is a valid conclusion?

- A) If I graduate, then I studied.
- B) If I pass, then I studied.
- C) If I study, then I graduate.
- D) If I graduate, then I pass.

---

**Question 12.**
Justify the step: In a proof, $m\angle 1 + m\angle 2 = 90°$ and $m\angle 2 = 35°$, so $m\angle 1 + 35° = 90°$.

- A) Reflexive Property
- B) Transitive Property
- C) Substitution Property
- D) Addition Property

---

**Question 13.**
Which of the following arguments uses **inductive** reasoning?

- A) All angles in an equilateral triangle are 60°; $\triangle ABC$ is equilateral; therefore $m\angle A = 60°$.
- B) The sum of angles in the first five triangles I measured was 180°; therefore all triangles have angle sum 180°.
- C) $AB = CD$ and $CD = EF$, so $AB = EF$ by the Transitive Property.
- D) Given two parallel lines cut by a transversal, alternate interior angles are congruent.

**Question 14.**

- B) Only the contrapositive
